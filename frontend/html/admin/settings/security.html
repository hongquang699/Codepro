Kiến Trúc Lá Chắn Phòng Thủ Toàn Diện (CodeProOJ Security Engine)

1. Chống Tấn Công DoS / DDoS (L7)
Sử dụng thuật toán Sliding Window Rate Limiter với độ trễ siêu thấp (<0.1ms). Kiểm soát tần suất truy cập riêng biệt cho Web UI, API và Submit code.
2. Chống IP Giả & Injection Header
Kiểm tra nghiêm ngặt định dạng IPv4/IPv6 chuẩn RFC 791/4291. Tự động từ chối ngay lập tức các request có chèn ký tự lạ, SQL injection hoặc mạo danh Proxy Header.
3. Triệt Tiêu Bot & Scanner Tự Động
Nhận diện và lập tức chặn đứng công cụ dò quét lỗ hổng: sqlmap, nikto, acunetix, gobuster, dirbuster, python-requests scrapers.
4. Bẫy Thăm Dò Khai Thác (Honeypot)
Bất kỳ địa chỉ IP nào cố tình truy cập các đường dẫn nhạy cảm như /.env, /wp-login.php, /.git, /actuator sẽ bị đưa ngay vào Jail giam giữ.
