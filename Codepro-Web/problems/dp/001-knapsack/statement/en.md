# 0/1 Knapsack Problem

Given $N$ items, each with weight $w_i$ and value $v_i$, and a knapsack with maximum weight capacity $W$. Find the maximum total value of items that can be put into the knapsack such that the total weight does not exceed $W$.

## Input
- The first line contains $N$ and $W$ ($1 \le N \le 1000$, $1 \le W \le 10000$).
- The following $N$ lines each contain two integers $w_i$ and $v_i$.

## Output
- Output a single integer: the maximum value.
