🔒 Ma Trận Phân Quyền Tổ Chức (Permissions Matrix)

Quy tắc kiểm soát truy cập dựa trên vai trò (Role-Based Access Control) cho từng tính năng.

Mã quyền (Permission Token) Mô tả chức năng Owner Admin Moderator Problem Setter Contest Manager Member
organization.view Xem trang tổng quan, danh sách bài tập & thành viên ✓ ✓ ✓ ✓ ✓ ✓
organization.edit Cập nhật hồ sơ, thương hiệu, website, cấu hình tổ chức ✓ ✓ ✗ ✗ ✗ ✗
member.view Xem danh sách và hồ sơ thành viên trong tổ chức ✓ ✓ ✓ ✓ ✓ ✓
member.add / invite Thêm trực tiếp hoặc gửi lời mời thành viên ✓ ✓ ✗ ✗ ✗ ✗
member.remove / ban Xóa hoặc cấm thành viên khỏi tổ chức ✓ ✓ ✗ ✗ ✗ ✗
member.manage Thay đổi vai trò (Role) và phân cấp bậc thành viên ✓ ✓ ✓ ✗ ✗ ✗
contest.create / edit Gán, khởi tạo và thiết lập cuộc thi thuật toán ✓ ✓ ✗ ✗ ✓ ✗
problem.create / edit Gán và quản lý bài tập chuyên đề trong tổ chức ✓ ✓ ✗ ✓ ✗ ✗
blog.create / edit Đăng tải và biên tập bài viết, blog tin tức ✓ ✓ ✓ ✗ ✗ ✗
announcement.create Phát hành thông báo chính thức có huy hiệu nổi bật ✓ ✓ ✓ ✗ ✗ ✗
