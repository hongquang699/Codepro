Bảng Thưa (Sparse Table) & Range Minimum Query

Cấu trúc dữ liệu tiền xử lý O(N log N) cho phép trả lời các truy vấn đoạn không đổi (Idempotent: min, max, gcd) trong O(1).

Thời gian đọc: ~15 phút Cấp độ: Cơ bản - Nâng cao ✍️ Biên soạn: CodeProOJ Academic Team

1. Nguyên lý Lũy thừa của 2

Bất kỳ khoảng [L, R] nào cũng có thể được phủ bởi 2 đoạn có độ dài là lũy thừa của 2: 2^k <= R - L + 1. Vì phép tìm min có tính chất phủ trùng (Idempotent): min(A, B) = min(min(A1, A2), min(A2, A3)), ta có thể truy vấn trong đúng O(1).

int st[20][MAXN];
int lg[MAXN];

void build(int n, const vector<int> &a) {
    lg[1] = 0;
    for (int i = 2; i <= n; i++) lg[i] = lg[i / 2] + 1;
    for (int i = 0; i < n; i++) st[0][i] = a[i];

    for (int j = 1; (1 << j) <= n; j++) {
        for (int i = 0; i + (1 << j) <= n; i++) {
            st[j][i] = min(st[j - 1][i], st[j - 1][i + (1 << (j - 1))]);
        }
    }
}

int query(int l, int r) {
    int j = lg[r - l + 1];
    return min(st[j][l], st[j][r - (1 << j) + 1]);
}
