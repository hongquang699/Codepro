Lý thuyết Đồ thị & Các Thuật toán Tìm đường

Tổng hợp toàn diện các thuật toán duyệt đồ thị BFS, DFS, đường đi ngắn nhất Dijkstra, Bellman-Ford, thành phần liên thông mạnh Tarjan và Cây khung nhỏ nhất Kruskal.

Thời gian đọc: ~20 phút Cấp độ: Cơ bản - Nâng cao ✍️ Biên soạn: CodeProOJ Academic Team

1. Biểu diễn đồ thị trong C++

Trong Competitive Programming, Danh sách kề (Adjacency List) sử dụng vector<vector<pair<int,int>>> là cách biểu diễn chuẩn nhất vì tính cơ động và tiết kiệm bộ nhớ O(V + E).

2. Thuật toán Dijkstra với Priority Queue

Tìm đường đi ngắn nhất từ một đỉnh nguồn đến tất cả các đỉnh còn lại trên đồ thị có trọng số không âm trong độ phức tạp O(E log V).

#include <bits/stdc++.h>
using namespace std;
const long long INF = 1e18;

void dijkstra(int s, int n, const vector<vector<pair<int,int>>> &adj, vector<long long> &d) {
    d.assign(n + 1, INF);
    priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<pair<long long, int>>> pq;
    d[s] = 0;
    pq.push({0, s});

    while (!pq.empty()) {
        auto [du, u] = pq.top();
        pq.pop();
        if (du > d[u]) continue;

        for (auto &edge : adj[u]) {
            int v = edge.first;
            int w = edge.second;
            if (d[u] + w < d[v]) {
                d[v] = d[u] + w;
                pq.push({d[v], v});
            }
        }
    }
}

3. Bảng tóm tắt Độ phức tạp các Thuật toán Đồ thị

Thuật toánBài toán giải quyếtĐộ phức tạp
BFS / DFSDuyệt đỉnh, kiểm tra liên thông, chu trìnhO(V + E)
Dijkstra (PQ)Đường đi ngắn nhất nguồn đơn (w >= 0)O(E log V)
Bellman-Ford / SPFAĐường đi ngắn nhất, phát hiện chu trình âmO(V * E)
Floyd-WarshallĐường đi ngắn nhất mọi cặp đỉnhO(V^3)
Kruskal / Prim (DSU)Cây khung nhỏ nhất (MST)O(E log E)
Tarjan / KosarajuThành phần liên thông mạnh (SCC)O(V + E)
