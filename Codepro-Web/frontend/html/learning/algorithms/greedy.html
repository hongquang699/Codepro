Thuật toán Tham lam (Greedy Algorithms)

Chiến lược lựa chọn phương án tối ưu cục bộ tại mỗi bước với hy vọng dẫn đến nghiệm tối ưu toàn cục.

Thời gian đọc: ~14 phút Cấp độ: Cơ bản - Nâng cao ✍️ Biên soạn: CodeProOJ Academic Team

1. Bản chất & Phương pháp Chứng minh Exchange Argument

Thuật toán tham lam hoạt động bằng cách luôn đưa ra lựa chọn có vẻ tốt nhất ở thời điểm hiện tại. Để chứng minh tính đúng đắn, kỹ thuật phổ biến nhất là Exchange Argument (Lập luận Đổi chỗ): Giả sử tồn tại lời giải tối ưu khác, ta chứng minh có thể đổi chỗ các phần tử để đưa về lời giải tham lam mà không làm giảm giá trị tối ưu.

2. Bài toán Xếp lịch công việc (Interval Scheduling)

Cho N công việc với thời gian bắt đầu và kết thúc [s_i, f_i]. Hãy chọn nhiều công việc nhất sao cho không có 2 công việc nào bị trùng thời gian.

📌 Chiến lược tham lam: Sắp xếp các công việc theo thời gian kết thúc f_i tăng dần. Luôn chọn công việc kết thúc sớm nhất tương thích với các công việc đã chọn trước đó. 
#include <bits/stdc++.h>
using namespace std;

struct Job { int s, f; };

int main() {
    int n; cin >> n;
    vector<Job> a(n);
    for (int i = 0; i < n; i++) cin >> a[i].s >> a[i].f;

    sort(a.begin(), a.end(), [](const Job &x, const Job &y) {
        return x.f < y.f;
    });

    int count = 0, last_end = -1;
    for (auto &job : a) {
        if (job.s >= last_end) {
            count++;
            last_end = job.f;
        }
    }
    cout << count << "\n";
}
