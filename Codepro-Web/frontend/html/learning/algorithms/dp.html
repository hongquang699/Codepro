Quy hoạch Động (Dynamic Programming - DP)

Phương pháp thiết kế giải thuật chia bài toán lớn thành các bài toán con gối nhau và lưu trữ kết quả để tránh tính toán trùng lặp.

Thời gian đọc: ~18 phút Cấp độ: Cơ bản - Nâng cao ✍️ Biên soạn: CodeProOJ Academic Team

1. Khái niệm cơ bản & Điều kiện áp dụng

Quy hoạch động (DP) là một trong những chủ đề quan trọng nhất trong lập trình thi đấu. Một bài toán có thể giải bằng DP khi thỏa mãn 2 tính chất vàng:

  • Cấu trúc con tối ưu (Optimal Substructure): Lời giải tối ưu của bài toán có thể tìm được từ lời giải tối ưu của các bài toán con.
  • Các bài toán con gối nhau (Overlapping Subproblems): Cùng một bài toán con được tính toán lại nhiều lần trong quá trình đệ quy.
💡 Công thức tư duy: Trạng thái DP (State) ➔ Cơ sở (Base Cases) ➔ Công thức chuyển trạng thái (Transitions) ➔ Thứ tự tính toán (Topological Order).

2. Bài toán Knapsack kinh điển (Cái balo 0/1)

Cho N đồ vật, mỗi đồ vật có trọng lượng w[i] và giá trị v[i]. Balo có sức chứa tối đa W. Hãy chọn các đồ vật sao cho tổng giá trị là lớn nhất.

// Knapsack 0/1 tối ưu không gian O(W)
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n, W;
    if (!(cin >> n >> W)) return 0;
    vector<int> w(n), v(n);
    for (int i = 0; i < n; i++) cin >> w[i] >> v[i];

    vector<long long> dp(W + 1, 0);

    for (int i = 0; i < n; i++) {
        // Duyệt ngược từ W về w[i] để mỗi đồ vật chỉ dùng tối đa 1 lần
        for (int j = W; j >= w[i]; j--) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }

    cout << dp[W] << "
";
    return 0;
}

3. Các dạng Quy hoạch động nâng cao

  • DP Bitmask: Lưu trạng thái tập hợp con bằng biểu diễn nhị phân (N <= 20).
  • DP trên Cây (Tree DP): Tính toán kết quả cho từng cây con gốc u dựa trên các nút con v.
  • DP Chữ số (Digit DP): Đếm số lượng số trong khoảng [A, B] thỏa mãn tính chất về các chữ số.
  • Tối ưu hóa DP: Convex Hull Trick, Knuth's Optimization, Divide & Conquer Optimization.
