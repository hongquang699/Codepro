Tìm kiếm Nhị phân & Chặt nhị phân kết quả

Kỹ thuật tối ưu hóa không gian tìm kiếm từ O(N) xuống O(log N) trên các hàm đơn điệu.

Thời gian đọc: ~12 phút Cấp độ: Cơ bản - Nâng cao ✍️ Biên soạn: CodeProOJ Academic Team

1. Binary Search trên tập nghiệm (Binary Search the Answer)

Kỹ thuật này được áp dụng khi bài toán yêu cầu: "Tìm giá trị X nhỏ nhất/lớn nhất thỏa mãn điều kiện P(X) = TRUE", và điều kiện P(X) có tính chất đơn điệu (Monotonicity): nếu P(X) đúng thì P(X+1) cũng đúng.

long long low = 1, high = 1e18, ans = -1;
while (low <= high) {
    long long mid = low + (high - low) / 2;
    if (check(mid)) {
        ans = mid;
        high = mid - 1; // Tìm giá trị nhỏ nhất thỏa mãn
    } else {
        low = mid + 1;
    }
}
